# Archived implementation notes

These files are retained for reference and may describe earlier implementations:

- `routes_snapshot.txt`: a historical routes source snapshot, previously `lib/copy.txt`.
- `local_state_notes.md`: older state-management advice, previously stored alongside local state code.
- `theme_notes.md`: older theme API notes; see `lib/theme/` and the project map for current names.

Use [the current project map](../project_structure.md) and the Dart source for
current behavior. Files in this directory are not compiled into the app.
