# Pending Hexora release notes

This directory is available for significant frontend only release drafts. Cross repository changes should maintain one canonical draft in the repository that owns the primary user facing behavior and reuse its `announcement_key` in this changelog.

Every draft must begin with the metadata fields documented in the repository `AGENTS.md`. New drafts start with `status: draft`, `verification: not_run`, and `release_status: unreleased`. Publication requires explicit user approval.
